# فوراپ (ForApp)

پیامک واریز بانک را روی گوشی می‌خواند و همان لحظه به وبهوک سرور شما می‌فرستد؛ دیگر لازم نیست واریزها را دستی ثبت کنید.

[دانلود آخرین نسخه](https://github.com/erfjab/forapp/releases/latest) · اندروید ۸ به بالا

## ویژگی‌ها

- **فقط بانک‌هایی که می‌خواهید:** بقیه‌ی پیامک‌ها خوانده نمی‌شوند.
- **کد تطبیق:** سه رقم آخر مبلغ جدا فرستاده می‌شود تا واریز هر مشتری خودکار پیدا شود.
- **مطمئن در اینترنت فیلترشده:** بی‌اتصالی تلاش حساب نمی‌شود و با وصل شدن، خودش می‌فرستد.
- **بدون ثبت تکراری:** هر واریز `Idempotency-Key` یکتای خودش را دارد.
- **درخواست دلخواه برای هر مقصد:** متد، هدرها و بدنه (JSON، فرم یا متن) با متغیرهایی مثل `{{amount}}`.
- **شفاف:** جزئیات، درخواست کامل و «ارسال الان» برای هر واریز؛ دو ویجت صفحه‌ی اصلی.
- **بدون سرور واسطه:** همه‌ی داده‌ها فقط روی گوشی شماست.

## راه‌اندازی

۱. APK را نصب کنید و قدم‌های راه‌اندازی را بروید: اجازه‌ی پیامک، باتری، بانک‌ها و مقصد.
۲. روی اندروید ۱۳ به بالا (و شیائومی) اگر اجازه‌ی پیامک داده نشد: «اطلاعات برنامه» ← منوی ⋮ ← **Allow restricted settings**.
۳. با «ارسال آزمایشی» مطمئن شوید سرورتان جواب می‌دهد.

## درخواست پیش‌فرض

```
POST <آدرس وبهوک>
X-API-Key: <کلید مقصد>
Idempotency-Key: <id>

{"id", "test", "sender", "bank", "body", "amount", "code", "unit",
 "is_deposit", "received_at", "received_at_ms", "attempt", "device"}
```

پاسخ 2xx یعنی رسید؛ 408، 425، 429 و 5xx دوباره تلاش می‌شوند؛ بقیه‌ی 4xx ناموفق‌اند.

## ساخت

```
./gradlew testDebugUnitTest assembleRelease
```

GitHub Actions با هر push به master یک APK می‌سازد و با هر تگ `v*` (مثلاً `v1.1.0`) یک Release منتشر می‌کند. کلید امضا در Secrets مخزن است (`FORAPP_KEYSTORE_B64` و `FORAPP_KEYSTORE_PASSWORD`).
